# NaturaGlow - Multi-page Business Website

NaturaGlow is a responsive multi-page business website created as part of my Web Development Internship with Next Gen Software Hub Pvt. Ltd.

The website represents a fictional natural skincare and beauty brand and demonstrates the integration of HTML, CSS, and JavaScript.

## Project Overview

The goal of this project was to build a complete multi-page business website with a clean, responsive, and user-friendly design.

The website includes:

- Home page
- About page
- Services page
- Contact page
- Responsive navigation
- Contact form validation
- SEO-friendly metadata
- Responsive layouts for desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- CSS Grid
- CSS Flexbox
- DOM Manipulation
- Form Validation
- SEO Meta Tags

## Features

### 1. Responsive Design

The website adapts to different screen sizes including:

- Desktop
- Tablet
- Mobile

### 2. Multi-page Navigation

The website contains four connected pages:

- Home
- About
- Services
- Contact

### 3. Mobile Navigation

A JavaScript-powered mobile menu allows users to open and close the navigation menu on smaller screens.

### 4. Product Showcase

The Services page displays a collection of fictional NaturaGlow skincare products with:

- Product name
- Description
- Price
- Responsive card layout

### 5. Contact Form

The Contact page contains a form with:

- Full name
- Email address
- Subject
- Message

JavaScript validates the form before displaying a success message.

### 6. Form Validation

The form checks:

- Empty fields
- Minimum name length
- Valid email format
- Minimum subject length
- Minimum message length

### 7. SEO

Each page includes:

- Page title
- Meta description
- Keywords
- Author metadata
- Semantic HTML structure

### 8. Visual Design

The website uses:

- Natural green color palette
- Gradient backgrounds
- Responsive cards
- Hover effects
- CSS animations
- Consistent spacing and typography

## How to Run the Project

- Download or clone the repository.
- Open the project folder.
- Open index.html in a web browser.
- Navigate between the Home, About, Services, and Contact pages.

For the best development experience, the project can also be opened using the Live Server extension in Visual Studio Code.
